## ▍ Flagship Systems

### 🧠 AgentForge-OS — Autonomous Multi-Agent Operating System
Supervisor-agent routing across **8+ specialized agents** for research, analytics, and automation. Fine-tuned on `microsoft/phi-2` via LoRA/QLoRA (adapted for Windows/CPU inference), retrieval through FAISS + ChromaDB, gated by RAGAS/LangSmith before any release.
`Python` `LangGraph` `CrewAI` `MLflow` `Docker` — **[View repo →](https://github.com/Yashvi-Vekariya/AgentForge-OS)**

### 🔍 Autonomous Research Agent — Web-Grounded Multi-Agent Platform
LangGraph orchestration, Tavily-grounded retrieval, GPT-4o reasoning, fully async. Cut manual research time by **65%** across parallel agent workflows.
`LangGraph` `LangChain` `FastAPI` `Docker` — **[View repo →](https://github.com/Yashvi-Vekariya/Autonomous-Research-Agent-with-Web-Grounding)**
